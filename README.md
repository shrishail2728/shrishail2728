## HealthTrack Pro

Real-time patient-health monitoring firmware for an ESP32 using FreeRTOS.

- [Open the HealthTrack Pro project](https://github.com/shrishail2728/HealthTrack-Pro)
- Sensors: MAX30102, AD8232, DHT22, and DS18B20
- Outputs: I²C LCD, serial ECG plotting, and ThingSpeak cloud logging
